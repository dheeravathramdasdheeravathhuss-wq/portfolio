# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, technical knowledge, and contact information in a clean, modern, and responsive design.

The portfolio is built using **HTML, CSS, and JavaScript** without any frameworks. It is designed to help recruiters, internship coordinators, and developers learn more about my work and technical abilities.

## 🎯 Project Overview

The Personal Portfolio Website is a professional online presence that highlights my background, technical skills, completed projects, and career goals. It provides an easy way for recruiters and collaborators to explore my work and contact me.

## ✨ Features

- **Hero Section:** Introduction, name, and professional tagline.
- **About Me:** Background, interests, and career objectives.
- **Skills Section:** Programming languages and technical skills.
- **Projects Section:** Showcases at least three projects with descriptions, technologies, and project links.
- **Contact Section:** Email and social media links.
- **Responsive Design:** Supports mobile, tablet, and desktop screens.
- **Interactive Elements:** JavaScript-powered navigation or other user interactions.
- **Semantic HTML:** Uses meaningful elements for a well-structured website.
- **Modern UI:** Clean layout, consistent typography, and attractive styling.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Make sure `index.html`, `style.css`, and `script.js` are in the correct locations.

4. Install the **Live Server** extension in VS Code.

5. Right-click `index.html` and select **Open with Live Server**.

6. Your portfolio website will open in your browser.

Alternatively, open `index.html` directly in your browser.

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- Mobile: 375px
- Tablet: 768px
